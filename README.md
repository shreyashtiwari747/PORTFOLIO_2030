shreyash tiwari — Personal Profile Website

📌 About the Project

This is a personal profile website created using HTML, CSS, and JavaScript. It introduces Mahak Sadhwani and provides sections for personal information, skills, projects, and contact details.

The website features a clean, modern design with a purple theme and a responsive layout for desktop and mobile devices.

✨ Features

Home: Introduction and welcome section.
About Me: Personal information, education, interests, and career goals.
Skills: A list of skills and areas of interest.
Projects: Project descriptions and links.
Contact: An email contact button.
Responsive Design: Adapts to different screen sizes.
Mobile Navigation: A toggle menu for smaller screens.
Dynamic Footer: Automatically displays the current year.
🛠️ Technologies Used

HTML5 — Website structure and content.
CSS3 — Styling, layout, animations, and responsive design.
JavaScript — Mobile navigation and dynamic footer year.
📂 Project Structure

mahak-profile/ │ ├── index.html ├── style.css ├── script.js └── README.md

🚀 How to Run the Project

Download or clone this repository.
Open the project folder.
Make sure all three files (index.html, style.css, and script.js) are in the same folder.
Open index.html in your web browser.
Navigate through the different sections to explore the website.
No additional libraries or installations are required.

⚙️ Customization

You can personalize the website by editing the following:

Personal information: Update the About Me section in index.html.
Skills: Replace the placeholder skills with your actual skills.
Projects: Add your project names, descriptions, and links.
Email: Replace PLACEHOLDER_EMAIL with your email address.
Design: Modify colors, fonts, spacing, and layout in style.css.
Functionality: Customize navigation and other interactions in script.js.
Remember to replace all PLACEHOLDER values before publishing the website.

📱 Responsive Design

The website uses CSS media queries to adapt its layout to different screen sizes. On smaller screens, the navigation changes to a toggle menu, and the project cards stack vertically.
